

## 1. PENDAHULUAN

### 1.1 Tujuan Dokumen
Dokumen ini mendefinisikan kebutuhan fungsional dan non-fungsional untuk pengembangan website portofolio profesional berbasis static HTML. Website ini berfungsi sebagai representasi digital profesional seorang Developer + Designer yang menggunakan AI sebagai alat bantu utama dalam setiap proyeknya.

### 1.2 Ruang Lingkup
Website portofolio ini merupakan aplikasi web statis (tanpa backend/database) yang dapat di-hosting di platform seperti GitHub Pages, Netlify, atau Vercel. Website menampilkan identitas profesional, keahlian teknis, dan karya-karya terbaik kepada calon klien atau rekruter.

### 1.3 Target Pengguna
- Calon klien yang mencari jasa web development
- Rekruter atau perusahaan yang mencari talent
- Sesama developer/desainer yang ingin berkolaborasi
- Siapapun yang ingin mengetahui profil dan karya profesional pemilik

### 1.4 Definisi & Singkatan
| Istilah | Keterangan |
|---|---|
| SRS | Software Requirements Specification |
| UI | User Interface |
| UX | User Experience |
| AI-Assisted | Proyek yang dikembangkan dengan bantuan kecerdasan buatan |
| Static | Website tanpa server-side processing |
| Responsif | Tampilan menyesuaikan ukuran layar perangkat |

## 2. DESKRIPSI UMUM SISTEM

### 2.1 Perspektif Produk
Website portofolio ini berdiri sendiri sebagai produk independen. Tidak terhubung ke sistem eksternal kecuali layanan pihak ketiga opsional seperti form kontak (Formspree) dan analytics (Google Analytics).

### 2.2 Fungsi Utama Sistem
- Menampilkan identitas dan branding profesional pemilik
- Memperkenalkan keahlian teknis secara visual dan terstruktur
- Menampilkan 3–5 proyek terbaik lengkap dengan deskripsi, teknologi, dan tautan
- Menyediakan saluran kontak langsung kepada pengunjung
- Menonjolkan keunggulan penggunaan AI dalam proses pengembangan

### 2.3 Karakteristik Pengguna
Pengunjung website diasumsikan memiliki pengetahuan dasar navigasi web, mengakses melalui berbagai perangkat (desktop, tablet, mobile), dan memiliki rentang perhatian pendek sehingga informasi harus tersampaikan dalam hitungan detik.

### 2.4 Asumsi & Ketergantungan
- Website diakses melalui browser modern (Chrome, Firefox, Safari, Edge versi terbaru)
- File-file aset (gambar, font) tersedia secara lokal atau via CDN
- Tidak memerlukan login atau autentikasi pengguna
- Koneksi internet diperlukan untuk memuat font Google/CDN

## 3. KEBUTUHAN FUNGSIONAL

### 3.1 Modul Navigasi (NAV)

**NAV-01 — Navbar Tetap (Sticky)**
Navbar selalu terlihat di bagian atas halaman saat pengguna melakukan scroll. Navbar memuat logo/nama pemilik di sisi kiri dan menu navigasi di sisi kanan.

**NAV-02 — Menu Navigasi**
Terdapat empat menu utama: Home, About, Projects, Contact. Setiap menu mengarah ke section yang sesuai dalam satu halaman (single-page).

**NAV-03 — Hamburger Menu (Mobile)**
Pada layar dengan lebar di bawah 768px, menu navigasi berubah menjadi ikon hamburger. Saat diklik, menu tampil sebagai dropdown atau overlay penuh.

**NAV-04 — Smooth Scroll**
Saat menu diklik, halaman melakukan scroll halus (smooth scroll) menuju section yang dituju.

**NAV-05 — Active State**
Menu yang sedang aktif (section yang sedang dilihat) mendapat penanda visual berbeda (underline, warna, atau berat font).

---

### 3.2 Modul Hero Section (HERO)

**HERO-01 — Heading Utama**
Menampilkan nama lengkap pemilik dalam tipografi besar dan tegas sebagai elemen visual paling dominan.

**HERO-02 — Tagline Profesional**
Menampilkan satu kalimat singkat yang mendeskripsikan peran profesional, contoh: "Developer & Designer — Crafting Digital Experience with AI Precision."

**HERO-03 — Badge AI-Assisted**
Menampilkan badge/label kecil bertuliskan "AI-Powered Workflow" atau "Built with AI Assistance" sebagai differensiasi kompetitif.

**HERO-04 — Call to Action (CTA)**
Terdapat minimal dua tombol CTA: tombol primer "Lihat Proyek" yang mengarah ke section Projects, dan tombol sekunder "Hubungi Saya" yang mengarah ke section Contact.

**HERO-05 — Animasi Masuk**
Elemen-elemen Hero muncul dengan animasi fade-in bertahap (staggered) saat halaman pertama kali dimuat.

---

### 3.3 Modul About (ABOUT)

**ABOUT-01 — Foto/Avatar Profesional**
Menampilkan foto profil pemilik dalam format persegi atau bulat. Jika tidak ada foto, digantikan dengan ilustrasi atau inisial nama dalam kotak berwarna.

**ABOUT-02 — Bio Singkat**
Paragraf 3–5 kalimat yang mendeskripsikan latar belakang, pendekatan kerja, dan passion pemilik. Menyebutkan secara eksplisit bahwa proyek dikembangkan dengan bantuan AI profesional.

**ABOUT-03 — Daftar Keahlian (Skills)**
Menampilkan daftar teknologi dan tools dalam format visual (badge/pill/tag), dikelompokkan ke dalam kategori: Frontend, Backend, Design Tools, dan AI Tools.

**ABOUT-04 — Statistik Singkat**
Menampilkan 3–4 angka pencapaian dalam format kartu metrik kecil, contoh: jumlah proyek selesai, tahun pengalaman, teknologi dikuasai, klien dilayani.

---

### 3.4 Modul Projects (PROJECT)

**PROJECT-01 — Grid Proyek**
Menampilkan 3–5 kartu proyek dalam layout grid responsif. Di desktop minimal 2 kolom, di mobile 1 kolom.

**PROJECT-02 — Kartu Proyek**
Setiap kartu proyek memuat: thumbnail/mockup proyek, nama proyek, deskripsi singkat (maksimal 2 kalimat), daftar teknologi yang digunakan dalam format badge, badge "AI-Assisted" jika relevan, tautan ke demo live, dan tautan ke repository GitHub (opsional).

**PROJECT-03 — Hover Effect**
Saat kartu proyek di-hover, terjadi efek visual halus seperti elevasi ringan, perubahan warna border, atau overlay dengan tautan.

**PROJECT-04 — Featured Project**
Satu proyek dapat ditandai sebagai "Featured" dan ditampilkan lebih besar atau lebih menonjol dibanding yang lain.

**PROJECT-05 — Filter Kategori (Opsional)**
Tombol filter untuk menyaring proyek berdasarkan kategori: All, Web App, Landing Page, UI/UX. Filter bekerja secara client-side tanpa reload halaman.

---

### 3.5 Modul Contact (CONTACT)

**CONTACT-01 — Form Kontak**
Formulir dengan field: Nama Lengkap (wajib), Alamat Email (wajib, validasi format), Subjek (wajib), dan Pesan (wajib, minimal 10 karakter).

**CONTACT-02 — Validasi Form**
Validasi dilakukan di sisi client (JavaScript) sebelum pengiriman. Pesan error tampil di bawah field yang tidak valid.

**CONTACT-03 — Pengiriman Form**
Form dikirim menggunakan layanan Formspree (static-friendly) tanpa backend. Setelah berhasil, tampil pesan sukses dan form direset.

**CONTACT-04 — Tautan Media Sosial**
Menampilkan ikon tautan ke profil profesional: GitHub, LinkedIn, Instagram (opsional), dan Email langsung.

**CONTACT-05 — Informasi Kontak Langsung**
Selain form, tampilkan alamat email dan/atau nomor WhatsApp yang bisa diklik langsung.

---

### 3.6 Modul Footer (FOOTER)

**FOOTER-01 — Copyright**
Menampilkan teks hak cipta dengan tahun yang diupdate otomatis via JavaScript.

**FOOTER-02 — Navigasi Cepat**
Tautan singkat ke setiap section utama untuk navigasi cepat dari bagian bawah halaman.

**FOOTER-03 — Atribusi**
Kalimat singkat seperti "Designed & Developed with AI Assistance" sebagai branding konsisten.

## 4. KEBUTUHAN NON-FUNGSIONAL

### 4.1 Performa

**PERF-01** — Halaman harus selesai dimuat (First Contentful Paint) dalam waktu di bawah 2 detik pada koneksi broadband standar.

**PERF-02** — Total ukuran halaman (HTML + CSS + JS tanpa gambar) tidak melebihi 500KB.

**PERF-03** — Gambar dioptimasi dan menggunakan format WebP atau JPEG dengan kompresi memadai. Ukuran tiap gambar tidak melebihi 300KB.

**PERF-04** — Font dimuat dari Google Fonts dengan atribut `display=swap` untuk mencegah flash of invisible text.

### 4.2 Responsivitas

**RESP-01** — Website tampil dengan sempurna pada tiga breakpoint utama: Mobile (320px–767px), Tablet (768px–1023px), Desktop (1024px ke atas).

**RESP-02** — Tidak ada elemen yang terpotong atau overflow secara horizontal pada semua ukuran layar.

**RESP-03** — Ukuran font, padding, dan spasi menyesuaikan secara proporsional antar breakpoint.

### 4.3 Kompatibilitas Browser

**COMPAT-01** — Website berfungsi penuh pada Chrome 100+, Firefox 100+, Safari 15+, dan Edge 100+.

**COMPAT-02** — Fitur CSS modern (CSS Grid, Flexbox, Custom Properties) digunakan dengan fallback jika diperlukan.

### 4.4 Aksesibilitas

**AKSES-01** — Semua gambar memiliki atribut `alt` yang deskriptif.

**AKSES-02** — Kontras warna antara teks dan background memenuhi standar WCAG 2.1 Level AA (rasio minimal 4.5:1 untuk teks normal).

**AKSES-03** — Website dapat dinavigasi menggunakan keyboard (Tab, Enter, Escape).

**AKSES-04** — Elemen interaktif memiliki focus indicator yang jelas.

### 4.5 Keamanan

**SEC-01** — Tidak ada data sensitif pengguna yang disimpan di sisi client (localStorage hanya untuk preferensi UI jika ada).

**SEC-02** — Semua tautan eksternal menggunakan atribut `rel="noopener noreferrer"` untuk mencegah tabnapping.

**SEC-03** — Form kontak menggunakan layanan pihak ketiga terpercaya (Formspree) yang menangani validasi dan pengiriman secara aman.

**SEC-04** — Website di-hosting menggunakan HTTPS.

**SEC-05** — Tidak ada penggunaan `eval()` atau injeksi HTML dinamis dari input pengguna.

### 4.6 Maintainability

**MAINT-01** — Kode HTML, CSS, dan JavaScript dipisahkan ke dalam file terpisah untuk kemudahan pengelolaan.

**MAINT-02** — CSS menggunakan Custom Properties (variabel) untuk warna, tipografi, dan spacing sehingga tema mudah diubah dari satu tempat.

**MAINT-03** — Komentar kode tersedia pada bagian-bagian kritis untuk memudahkan modifikasi di masa depan.

**MAINT-04** — Data proyek disimpan dalam satu objek JavaScript terstruktur agar mudah diupdate tanpa menyentuh markup HTML.

## 6. DESAIN VISUAL

### 6.1 Palet Warna
| Nama | Kode Hex | Penggunaan |
|---|---|---|
| Primary Black | #0A0A0A | Teks utama, heading |
| Off White | #F8F7F4 | Background utama |
| Accent | #1A1A1A | Border, elemen subtle |
| Highlight | #E8E4DC | Surface card, background secondary |
| Link/CTA | #111111 | Tombol, tautan aktif |

### 6.2 Tipografi
| Peran | Font | Weight | Ukuran |
|---|---|---|---|
| Display / Heading Besar | Playfair Display | 700 | 64–96px |
| Heading Section | DM Serif Display | 400 | 36–48px |
| Body Text | DM Sans | 400 | 16–18px |
| Label / Caption | DM Sans | 500 | 12–14px |
| Code / Tech Badge | JetBrains Mono | 400 | 12–13px |

### 6.3 Prinsip Layout
- Penggunaan negative space yang melimpah (generous whitespace)
- Tipografi sebagai elemen visual utama, bukan dekorasi
- Grid asimetris pada section hero dan about
- Baris dekoratif horizontal tipis sebagai pemisah section yang elegan
- Animasi subtle: fade-in, slide-up dengan delay bertahap

## 7. BATASAN SISTEM

- Website tidak memiliki CMS, sehingga pembaruan konten dilakukan langsung pada kode
- Tidak mendukung multi-bahasa pada versi 1.0
- Form kontak bergantung pada layanan Formspree (memerlukan koneksi internet dan akun Formspree aktif)
- Tidak ada fitur blog atau artikel pada versi ini
- Animasi kompleks dinonaktifkan secara otomatis jika pengguna mengaktifkan `prefers-reduced-motion`
